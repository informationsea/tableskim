Choose the file for your system below.

Windows

For 64-bit Windows (x64). Both contain TableSkim.exe, the GUI, and tableskim-tui.exe, the terminal UI.

Installer

Recommended

tableskim-<version>-Windows-AMD64.exe

Installs TableSkim with Start menu entries, including the user manual. The usual choice.

Download

Portable ZIP

Recommended

tableskim-<version>-Windows-AMD64.zip

Needs no installation or administrator rights: unpack it anywhere and run TableSkim.exe.

Download

macOS

For macOS 12 (Monterey) or later. The app is not signed with a developer certificate: the first time, Control-click TableSkim.app and choose Open (more).

Linux

For x86-64. The packages install the tableskim command and a desktop entry; the ZIPs need no installation and run on any distribution with glibc 2.28 or later (RHEL 8, Debian 10, Ubuntu 20.04 and newer): unpack one anywhere and run bin/tableskim.

Packages

Debian package

Recommended

tableskim_<version>_ubuntu24.04_amd64.deb

For Ubuntu 24.04 or later and other distributions as new. Install with sudo apt install ./tableskim_*.deb.

Download

RPM package

Recommended

tableskim-<version>-1.rocky10.x86_64.rpm

For RHEL 10 and its rebuilds (Rocky Linux, AlmaLinux). Install with sudo dnf install ./tableskim-*.rpm.

Download

Portable ZIPs

GUI and terminal UI

Recommended

tableskim-<version>-Linux-x86_64.zip

The GUI for Wayland and X11, and the terminal UI. The usual choice on a desktop.

Download

GUI for X11 only

Recommended

tableskim-<version>-Linux-x11-x86_64.zip

Needs no Wayland libraries (libwayland, libxkbcommon, libdecor, D-Bus). For X11 desktops, X forwarding over SSH, or when the other ZIP misses a library.

Download

Terminal UI only

Recommended

tableskim-tui-<version>-Linux-x86_64.zip

The smallest download, with no graphics libraries at all. For servers and clusters without a desktop, used over SSH.

Download

Web browser

TableSkim for the browser, to put on your own web server: the files it opens are read in the browser and never uploaded. Unpack the ZIP and place the folder anywhere on a server with HTTPS (or localhost), then open the folder's URL, with the slash at the end. The included README.txt tells more.

Web app

tableskim-<version>-web.zip

Static files only: no server-side program is needed. Hosts that cannot send the cross-origin isolation headers, such as GitHub Pages, work too.
