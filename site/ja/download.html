TableSkim のダウンロード

どのファイルにも必要なライブラリがすべて組み込まれているので、ほかに何もインストールする必要はありません。 TableSkim は無料のオープンソースです（AGPL-3.0）。

お使いのシステムへのおすすめ

これは Apple シリコン（M1 以降）の Mac 用です。 Intel プロセッサの Mac では、Intel 用のディスクイメージを選んでください。

この PC は ARM プロセッサのようです。 Windows 版は x64 用ですが、ARM 版 Windows 11 ではエミュレーションで動きます。

このコンピュータは ARM プロセッサのようです。 Linux 版は x86-64 専用です。ARM では ソースからビルドしてください。

ほかのファイルが必要な場合は、下の一覧から選んでください。

お使いのシステムに合ったファイルを下から選んでください。

Windows

64 ビット版 Windows（x64）用です。どちらにも GUI の TableSkim.exe と、 ターミナル UI の tableskim-tui.exe が含まれます。

インストーラー

おすすめ

tableskim-<version>-Windows-AMD64.exe

TableSkim をインストールし、ユーザーマニュアルを含むスタートメニューの項目を追加します。通常はこちらを選んでください。

ダウンロード

ポータブル ZIP

おすすめ

tableskim-<version>-Windows-AMD64.zip

インストールも管理者権限も不要です。好きな場所に展開して TableSkim.exe を実行します。

ダウンロード

macOS

macOS 12（Monterey）以降用です。アプリは開発者証明書で署名されていないため、 初回は TableSkim.app を Control キーを押しながらクリックして開くを選んでください （詳しく）。

Apple シリコン（M1 以降）

ディスクイメージ

おすすめ

tableskim-<version>-Darwin-arm64.dmg

開いて TableSkim.app をアプリケーションフォルダにドラッグします。通常はこちらを選んでください。

ダウンロード

ZIP

おすすめ

tableskim-<version>-Darwin-arm64.zip

同じ TableSkim.app とマニュアルを ZIP にしたものです。スクリプトでのインストールや、 ディスクイメージをマウントしたくない場合に。

ダウンロード

Intel

ディスクイメージ

おすすめ

tableskim-<version>-Darwin-x86_64.dmg

Intel プロセッサの Mac 用です。開いて TableSkim.app をアプリケーションフォルダにドラッグします。

ダウンロード

ZIP

おすすめ

tableskim-<version>-Darwin-x86_64.zip

Intel 用の TableSkim.app とマニュアルを ZIP にしたものです。

ダウンロード

Linux

x86-64 用です。パッケージは tableskim コマンドとデスクトップエントリをインストールします。 ZIP はインストール不要で、glibc 2.28 以降のどのディストリビューション（RHEL 8、Debian 10、Ubuntu 20.04 以降）でも動きます。 好きな場所に展開して bin/tableskim を実行してください。

パッケージ

Debian パッケージ

おすすめ

tableskim_<version>_ubuntu24.04_amd64.deb

Ubuntu 24.04 以降と、同程度に新しいディストリビューション用です。 sudo apt install ./tableskim_*.deb でインストールします。

ダウンロード

RPM パッケージ

おすすめ

tableskim-<version>-1.rocky10.x86_64.rpm

RHEL 10 とその互換ディストリビューション（Rocky Linux、AlmaLinux）用です。 sudo dnf install ./tableskim-*.rpm でインストールします。

ダウンロード

ポータブル ZIP

GUI とターミナル UI

おすすめ

tableskim-<version>-Linux-x86_64.zip

Wayland と X11 に対応した GUI と、ターミナル UI。デスクトップでは通常こちらを選んでください。

ダウンロード

X11 専用の GUI

おすすめ

tableskim-<version>-Linux-x11-x86_64.zip

Wayland のライブラリ（libwayland、libxkbcommon、libdecor、D-Bus）が不要です。X11 のデスクトップや SSH の X 転送、もう一方の ZIP でライブラリが足りない場合に。

ダウンロード

ターミナル UI のみ

おすすめ

tableskim-tui-<version>-Linux-x86_64.zip

グラフィックスのライブラリを一切使わない、最も小さなファイルです。デスクトップのないサーバーやクラスタで SSH 越しに使う場合に。

ダウンロード

インストールしたら

tableskim data.csv          # ディスプレイがあれば GUI
tableskim -t data.parquet   # ターミナル UI
