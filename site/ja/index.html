TableSkim

表形式のファイルを軽快に閲覧するためのビューア。大きな CSV、Excel ブック、 Parquet や JSON、DuckDB / SQLite データベースを開いて、すぐにスクロールを始められます。

ダウンロード ユーザーマニュアル GitHub のソースコード

Linux · macOS · Windows — 無料のオープンソース（AGPL-3.0）

開いたらすぐに見られる

行はバックグラウンドのスレッドで読み込まれ、その間もウィンドウは操作できます。数百万行のファイルもすぐに開きます。 Parquet ファイルやデータベースの並べ替えとフィルタは DuckDB や SQLite の中で実行されるので、どんな大きさの表でも使えます。

必要なライブラリはすべて組み込まれたネイティブ版を配布しているので、ほかに何もインストールする必要はありません。

1 つのプログラムに 2 つの画面

同じ tableskim コマンドが、ディスプレイがあればデスクトップのウィンドウを、なければターミナル UI を開きます。 SSH 接続先でも便利です。どちらでも同じ機能が使えます。

対応ファイル形式

  • CSV / TSV
  • gzip · bzip2 · xz · zstd 圧縮テキスト
  • VCF
  • Excel（.xlsx, .xlsm）
  • Parquet
  • JSON · NDJSON / JSON Lines
  • DuckDB
  • SQLite

テキストは UTF-8、UTF-16、Shift_JIS（CP932）を自動で判別して読み込みます。 ブックの各シート、データベースの各テーブルとビューはそれぞれシートとして表示されます。 対応ファイル形式の詳細 →

機能

並べ替え・フィルタ・検索

いくつの列にもフィルタをかけられ、値は型に応じて比較されます。数値は数として、日付は日や時刻で、真偽値は TRUE / FALSE として比較し、正規表現も使えます。

フィルタ →

列の統計

フィルタ後の行について、行数・空の数・異なる値の数、最小 / 最大、合計、平均、標準偏差、よく出る値を表示します。

統計 →

グラフ

ヒストグラム、相関係数と回帰直線つきの散布図、2 次元の密度分布、箱ひげ図。棒をダブルクリックするとその行に絞り込めます。 グラフは PNG や SVG で保存できます。

グラフ →

集計（Group By）

列の値ごとに行数を数え、ほかの列の合計・平均・最小・最大などを求めて、別のシートに表示します。

集計 →

SQL

DuckDB、SQLite、Parquet、JSON ファイルにクエリを実行し、結果をシートとして表示します。 履歴はすべてのウィンドウで共有され、Tab でテーブル名・列名・キーワードを補完できます。

SQL →

エクスポートと変換

並べ替え・フィルタ後の表示どおりに（非表示の列を除いて）CSV、TSV、Excel、Parquet に保存したり、 テキストファイルを型つきの Parquet や DuckDB に変換したりできます。

エクスポート →

セルの編集

編集モードで CSV / TSV・Excel ファイルのセルを編集できます。元に戻す・貼り付けにも対応。 保存時には編集した行だけを書き換え、文字コードや圧縮はそのまま保ちます。

セルの編集 →

伸びていくファイルへの追従

tail -f のように、CSV / TSV ファイルに追記された行を読み込みます。 フィルタ・統計・グラフも追記に合わせて更新されます。

GUI の使い方 →

列の多い表も見やすく

列の非表示と固定、行・セル・列名を指定した移動、列ごとの数値や日付の表示形式を設定できます。

キーボードショートカット →

ダウンロード

各プラットフォーム用のパッケージには、必要なライブラリがすべて組み込まれています。 ダウンロードページでは、お使いのシステムに合ったファイルを提案し、各ファイルを説明しています。

プラットフォームパッケージ
Linux.deb（Ubuntu 24.04 以降）、.rpm（RHEL 10 とその互換ディストリビューション）、 または glibc 2.28 以降のどのディストリビューションでも動く .zip（GUI とターミナル UI、X11 専用の GUI、ターミナル UI のみ）
macOS.dmg ディスクイメージ、または TableSkim.app を含む .zip
Windowsインストーラー（.exe）または .zip

ダウンロードするファイルを選ぶ

ファイルを開くには：

tableskim data.csv          # ディスプレイがあれば GUI
tableskim -t data.parquet   # ターミナル UI
