# 並べ替え・フィルタ・検索・統計

[← 目次](README.md)

このページでは、TableSkim が値をどのように比較するかを説明します。規則は
GUI とターミナル UI で共通で、どのファイル形式でも同じです。

## 値と型

セルには、空（NULL）、文字列、整数、小数、真偽値（TRUE / FALSE）、日付、日時のいずれかが入ります。Excel、Parquet、JSON、データベースのファイルはこれらの型を保持しています。CSV / TSV ファイルではすべてのセルが文字列ですが、
TableSkim は次のものを認識します。

- **数値**：`42` や `-3.5` のような文字列
- **日付と日時**（ISO 形式）：`2024-01-31`、`2024-01-31 12:34`、
  `2024-01-31T12:34:56.789`
- **真偽値**：真偽値と比較するときの `TRUE` / `FALSE`、`yes` / `no`、
  `1` / `0`（大文字・小文字は問わない）

## 並べ替え

- 並べ替えは 1 列ずつ、昇順か降順で行います。3 回目のクリック（GUI）や
  `o`（TUI）でファイルの順序に戻ります。
- **空のセルは、昇順でも降順でも常に最後** になります。
- 昇順では、数値（数値の文字列、真偽値、日付を含む）が文字列より前に来て、数値として比較されます。そのため `9` は `10` より前です。
- 文字列は（UTF-8 の）バイト単位で比較するので、大文字が小文字より前になります。
- 値が等しい行は、ファイル内の順序を保ちます。

CSV / TSV と Excel ファイルでは、並べ替えの前にシート全体をメモリに読み込みます。Parquet、JSON、データベースでは並べ替えをデータベース内で行うので、どんなに大きな表でも使えます。

## フィルタ

フィルタは **条件** の並びで、**All**（AND：すべての条件に一致）か **Any**
（OR：少なくとも 1 つに一致）で組み合わせます。各条件は 1 つの列を調べます。

### 演算子

| 演算子              | 一致するセル                                                      |
| ------------------- | ----------------------------------------------------------------- |
| `contains`          | 文字列を含む（大文字・小文字を区別しない）                        |
| `not contains`      | 文字列を含まない（大文字・小文字を区別しない）                    |
| `=`                 | 値と等しい（下記参照）                                            |
| `≠`                 | 値と等しくない                                                    |
| `<` `≤` `>` `≥`     | 値より小さい / 以下 / 大きい / 以上                               |
| `is empty`          | 空（NULL または空文字列）                                         |
| `is not empty`      | 空でない                                                          |
| `matches`           | 正規表現に一致する部分を含む（大文字・小文字を区別しない）        |
| `not matches`       | 正規表現に一致する部分を含まない                                  |
| `is a number`       | 数値または数値の文字列（真偽値、日付、NaN、無限大を除く）         |
| `is a date`         | 日付、日時、または数値でない ISO 形式の日付の文字列               |

### `=`・`≠`・`<`・`≤`・`>`・`≥` の比較方法

比較の仕方は、セルの値と入力した値によって決まります。

- **数値**：セルと値がどちらも数値（数値の文字列を含む）なら、数値として比較します。`Age ≥ 45` は 45、50、`"60"` に一致します。数値でないセルは文字列として比較する（下記参照）ので、`"abc"` も `"45"` より後に並ぶため一致します。数値だけに絞るには `is a number` を加えてください。
- **日付**：日付・日時のセル（または ISO 形式の日付文字列）を日付・日時の値と比較するときは、時刻として比較します。**日付の値はその日全体を表す** ので、
  `= 2024-01-31` は `2024-01-31 08:00` にも `2024-01-31 23:59` にも一致し、
  `< 2024-02-01` はその日より前のすべてに一致します。
- **真偽値**：真偽値のセルを `TRUE` / `FALSE`、`yes` / `no`、`1` / `0` と比較します。
- **文字列**：それ以外はバイト単位の文字列として比較するので、文字列の `=` は大文字・小文字を区別します。区別したくないときは `contains` か `matches` を使ってください。

### 正規表現

`matches` と `not matches` は [RE2 構文](https://github.com/google/re2/wiki/Syntax)
を使い、大文字・小文字を区別しません。パターンはセル内のどこに一致してもかまいません。セル全体と一致させるには、`^(Tokyo|Osaka)$` のように `^` と `$`
で囲みます。正しくないパターンはエラーとして知らせ、フィルタは適用しません。

### 例

| 目的                                         | 条件                                         |
| -------------------------------------------- | -------------------------------------------- |
| 東京在住で 45 歳以上の人                     | `City = Tokyo` **かつ** `Age ≥ 45`（Match: All） |
| 2024 年 1 月の行                             | `Date ≥ 2024-01-01` **かつ** `Date < 2024-02-01` |
| 時刻を問わず特定の日の行                     | `Timestamp = 2024-01-31`                     |
| example.com か example.org のメールアドレス  | `Email matches @example\.(com\|org)$`         |
| 値が欠けている行                             | `Salary is empty`                            |
| 東京または大阪                               | `City = Tokyo`、`City = Osaka`（Match: Any） |

### クイックフィルタ

クイックフィルタ（GUI のセルメニューの `Filter: = "値"`、TUI の `=` / `!`）は、セルに表示されている値で `=` / `≠` の条件を追加します。その条件は上で説明したとおり型に応じて比較されます。空のセルでは `is empty` / `is not empty` を追加します。すでにフィルタにある条件は二重には追加しません。

## 検索

- 検索は現在のシートの **すべてのセル** を、現在の並べ替えとフィルタの状態で調べます。
- 大文字・小文字を区別せず、表示されているセルの文字列のどこにあっても一致します。
- **Regex**（GUI）や `Ctrl+R`（TUI）を使うと、検索文字列を RE2 の正規表現として扱います。
- 一致したセルは強調表示されます。検索はバックグラウンドで実行されるので、大きなファイルを調べている間も作業を続けられます。

## 列の統計

統計は、現在の表示（フィルタ適用後）の行を対象に、1 つの列について計算します。

| 項目           | 意味                                                         |
| -------------- | ------------------------------------------------------------ |
| Rows           | 行数                                                         |
| Empty          | 空のセル（NULL または空文字列）の数と割合                    |
| Distinct       | 空でない値の種類の数                                         |
| Numbers        | 数値のセル（数値の文字列を含む）の数                         |
| Min / Max      | 並べ替え順での最小値と最大値                                 |
| Sum / Mean     | 数値の合計と平均                                             |
| Std dev        | 数値の標準偏差                                               |
| Most frequent  | 最も多い値と、その件数・割合                                 |

フィルタを変えると統計は計算し直されます。Parquet、JSON、DuckDB ファイルでは値の集計をデータベース内で行います。

## ヒストグラム

ヒストグラムは、列の統計と同じく、現在の表示（フィルタ適用後）の行を対象に
1 つの列を集計します。GUI では **Edit → Histogram...**
（[GUI の使い方](gui.md#ヒストグラム) を参照）、ターミナル UI では `B`
（[ターミナル UI の使い方](tui.md#ヒストグラム) を参照）で開きます。

### 集計の対象

列の値は、フィルタと同じ方法で読み取ります。

- **数値**：整数、小数、数値の文字列
- **時刻**：日付、日時、ISO 形式の日付文字列（`2024-01-31`、
  `2024-01-31 12:34`）

両方を含む列では、多いほうの種類を集計します。もう一方の種類の値は概要に「other values」（その他の値）として、空のセルは「empty」として表示されます。数値も日付も含まない列では、代わりに **最頻値** を表示します。

### 区間の決め方

読みやすい幅で、およそ **30 個の区間（ビン）** になるようにします。

- **数値**：幅は 1、2、5 に 10 の累乗を掛けた値（…、0.1、0.2、0.5、1、2、5、
  10、20、50、…）で、区間は幅の倍数から始まります。整数の列では幅を 1 以上にし、値の範囲が 30 以内なら **値ごとに 1 区間** にします。
- **時刻**：秒、分、時、日、週（月曜始まり）、月、年のうち、約 30 区間になる単位を使います。月と年は暦に従うので、月の区間はちょうど 1 か月分です。

各区間は下限を含み、上限を含みません。これを `[下限, 上限)` と書きます。最大値も数えられるよう、数値の最後の区間だけは上限も含み、`[下限, 上限]` と書きます。

### 棒から絞り込む

棒を選ぶ（GUI ではダブルクリック、TUI では `Enter`）と、フィルタに
`is a number`（時刻では `is a date`）、`≥ 下限`、`< 上限`（数値の最後の区間では `≤ 上限`）の 3 つの条件を追加します。これにより、ちょうどその棒に数えられた行だけが残ります。最初の条件は「その他の値」を除くためのもので、これがないと `15 kg` のような文字列も、文字列として `≥ 10` と `< 20` を満たしてしまいます。年・月・日の区間では、`≥ 1994-01-01` と `< 1996-01-01` のように境界が日付になります。文字列の列では、棒の値が `=` の条件として追加されます。追加された条件は
Filter ペイン（TUI では `f`）で確認・編集できます。

Parquet、JSON、DuckDB ファイルでは、値の集計をデータベース内で行います。

## 散布図と二次元密度分布

散布図は、現在の表示の行を対象に、ある列（X）を別の列（Y）に対して描きます。二次元密度分布は、それらの行をマス目ごとに数えます。GUI では **Edit → Scatter Plot...**（[GUI の使い方](gui.md#散布図と二次元密度分布) を参照）、ターミナル UI では密度分布のみを `M`（[ターミナル UI の使い方](tui.md#二次元密度分布) を参照）で開きます。

- 各列は [ヒストグラム](#集計の対象) と同じく、数値か時刻のうち多いほうとして読みます。両方の値がその列の種類である行だけを描き、それ以外の行は「skipped」として報告します。
- マス目は各列のヒストグラムの区間で、[上記](#区間の決め方) と同じ方法で決めますが、GUI では各軸およそ 50 区間、TUI ではターミナルに収まる数になります。
- 密度分布はすべての行を数えます。GUI の散布図の点は、最大 **20 万** 行の無作為な抽出で、毎回同じ行が選ばれます。
- **r** は描いた行のピアソンの相関係数、**R²** はその 2 乗、直線 `y = a x + b` は Y を X で回帰した最小二乗法の直線です。日付は時点として扱うので *r* は日付でも計算できますが、直線の式は数値のときだけ表示します。列の値が 1 種類しかないときは *r* は定義されません。

X がテキストのときは、その値のうち多いもの 30 個（ヒストグラムの「最も多い値」と同じ順）がカテゴリになり、残りの値はまとめて **(other)** になります。カテゴリごとに Y の値の箱ひげ図を描きます。

- 四分位数は、表計算ソフトの `QUARTILE.INC` と同じく、近い 2 つの値の間を線形に補間して求めます（1、2、…、8 の第 1 四分位数は 2.75）。
- ひげは、箱から四分位範囲（Q3 − Q1）の 1.5 倍以内にある最も遠い値までです。それより外の値は外れ値です。
- 平均は値の平均です。

箱を選ぶ（GUI ではダブルクリック、TUI では `Enter`）と、X にカテゴリの値の `=`、Y に `is a number`（または `is a date`）の条件を追加します。「(other)」は 1 つの値ではないので選べません。

マスを選ぶ（GUI ではダブルクリック、TUI では `Enter`）と、両方の列の区間の条件をフィルタに追加します。これにより、ちょうどそのマスに数えられた行だけが残ります。GUI で長方形をドラッグすると、両方の列に `is a number`（または `is a date`）、`≥`、`≤` の条件を追加します。境界は区間より少し細かく丸められます。

## 集計（Group By）

GUI の **Edit → Group By...**（[GUI の使い方](gui.md#集計group-by) を参照）とターミナル UI の `A`（[ターミナル UI の使い方](tui.md#集計group-by) を参照）は、現在の表示の行をいくつかの列の値ごとに数えます。

- グループ化するすべての列で値が等しい行が 1 つのグループになります。値が等しいのは同じ値のときだけで、テキストの `1`、`01`、`1.0` は並べ替えでは同順でも、別々の 3 つのグループになります。空のセル（短い行で欠けているセルも）は 1 つのグループになり、最後に並びます。
- グループは、[並べ替え](#並べ替え) と同じ順序で、グループの値（最初にグループ化した列から）の順に並びます。
- 要約は [列の統計](#列の統計) に従います。**count** と **distinct** は空でない値を数え、**sum**、**mean**、**std dev**（標本標準偏差）は数値（数値として読めるテキストを含む）を使い、**min** と **max** は並べ替え順で最初と最後の値なので、数値はテキストより前になります。
- 値がすべて異なる列でグループ化すると 1 行ごとのグループになります。グループが 100 万を超えると、エラーで集計を中止します。
