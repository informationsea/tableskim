# 対応ファイル形式

[← 目次](README.md)

TableSkim はファイル名と先頭のバイト列から形式を判断します。Parquet、DuckDB、SQLite のファイルは先頭のバイト列で判別するため、別の拡張子でも開けます。また、`{` や `[` で始まるテキストは JSON として読みます。下表の拡張子は一般的なものです。どの形式も同じウィンドウで開きます。複数の表を含む形式では、表ごとに **シート**（GUI ではウィンドウ下部、ターミナル UI では上部のタブ）として表示します。

| 形式             | 拡張子                                                    | シート                 |
| ---------------- | --------------------------------------------------------- | ---------------------- |
| CSV              | `.csv`                                                    | 1 つ                   |
| TSV              | `.tsv`、`.tab`                                            | 1 つ                   |
| VCF              | `.vcf`、`.vcf.gz`、`.vcf.bgz`                             | 1 つ                   |
| その他のテキスト | `.txt`、およびテキストに見える未知の拡張子                | 1 つ                   |
| Excel            | `.xlsx`、`.xlsm`                                          | ワークシートごと       |
| Parquet          | `.parquet`                                                | 1 つ                   |
| JSON             | `.json`、`.ndjson`、`.jsonl`                              | 1 つ                   |
| DuckDB           | `.duckdb`、`.ddb`                                         | テーブル・ビューごと   |
| SQLite           | `.sqlite`、`.sqlite3`、`.db`、`.db3`                      | テーブル・ビューごと   |

![複数のワークシートを持つ Excel ブック](../images/gui-multisheet.png)

## CSV、TSV、その他のテキストファイル

- 区切り文字は `.csv` ではカンマ、`.tsv`・`.tab`・`.vcf` ではタブです。その他のテキストファイルでは自動判定します。
- 行ごとに項目数が違っていても（**不揃いな行**）読めます。足りないセルは空欄で表示します。
- カンマ、引用符、改行を含む引用符付きの項目に対応しています。
- 並べ替え、フィルタ、統計では数値・日付・真偽値として扱いますが、表示はファイルに書かれたとおりの文字列です。
- **Use first row as header**（View メニュー、ターミナル UI では `H`）で先頭行を列名として使います。既定ではオフです。

### 圧縮ファイル

**gzip**（`.gz`、`.bgz`）、**bzip2**（`.bz2`）、**xz**（`.xz`）、
**zstd**（`.zst`）で圧縮された CSV / TSV / VCF ファイルは、その場で展開しながら読みます。例：`data.csv.gz`、`variants.vcf.bgz`。

### 文字コード

CSV / TSV ファイルは **UTF-8**（BOM の有無を問わず）、**UTF-16LE /
UTF-16BE**（BOM の有無を問わず）、日本語版 Excel が書き出す
**Shift_JIS（CP932）** に対応しています。文字コードはファイルの先頭から自動判定します。判定が誤っているときは、次の方法で切り替えます。

- GUI：**View → Text Encoding** から選ぶ
- ターミナル UI：`E` を押すたびに次の文字コードに切り替わる
- コマンドライン：`--encoding utf-8 | utf-16le | utf-16be | cp932`

### VCF と `##` 行

`##` で始まる行（VCF のメタ情報行など）は **View → Skip lines starting
with ##**（ターミナル UI では `#`）で読み飛ばせます。`.vcf` ファイルでは既定でオンなので、`#CHROM ...` の行が先頭行になります。

### 大きなテキストファイルとメモリ

CSV / TSV ファイルには索引がないため、並べ替えやフィルタのために、読み込んだ行をメモリに保持します。その行が約 **100 MB**、**500 MB**、**1 GB**、以降
**2 GB** ごとのメモリを使うと、読み込みを一時停止して続けるかどうかを尋ねます。

- **Continue**：ファイルの読み込みを続けます。
- **Stop Reading**：ファイルがそこで終わっているものとして、読み込み済みの行だけを表示します。

非常に大きなテキストファイルを繰り返し扱う場合は、一度 Parquet か DuckDB に変換しておくことをおすすめします（[エクスポートと変換](exporting.md) を参照）。これらの形式では並べ替えやフィルタがデータベース内で行われ、全行を読み込む必要がありません。

## Excel

- `.xlsx` と `.xlsm` のブックに対応しています。ワークシートごとに 1 つのシートになります。
- 日付（1904 年起点の日付システムのブックを含む）、数値、真偽値は型を保ったまま読み込みます。
- 結合セルの値は、結合範囲の左上のセルに表示します。範囲内のほかのセルは空欄になります。
- **Use first row as header** は CSV と同様に使えます。

## Parquet

Parquet ファイルは DuckDB を通して読みます。並べ替えとフィルタは DuckDB の中で行われるので、どんなに大きなファイルでも使えます。Parquet ファイルに
SQL を実行することもできます（[SQL の実行](sql.md) を参照）。

## JSON

- オブジェクトの配列（`[{...}, {...}]`）、または 1 行に 1 オブジェクトの形式（NDJSON / JSON Lines、`.ndjson`、`.jsonl`）に対応しています。
- gzip や zstd で圧縮された JSON（`.json.gz`、`.jsonl.zst` など）も読めます。
- オブジェクトのキーが列になります。入れ子のオブジェクトや配列は、
  `{'name': user1, 'tags': [a]}` や `[1, 2, 3]` のように文字列で表示します。
- JSON ファイルには SQL を実行できます。

## DuckDB と SQLite のデータベース

データベースのテーブルとビューを、それぞれシートとして表示します。並べ替えとフィルタはデータベースの中で行われるので、大きなテーブルでも高速です。DuckDB ではテーブルをビューより先に、`main` スキーマのものを先に並べ、ほかのスキーマのものは `スキーマ.テーブル` という名前にします。名前が重なった場合（スキーマ `a` のテーブル `b` と、`main` の `a.b` という名前のテーブル）は、先に並ぶ方をシートとして表示します。もう一方は SQL で参照してください。データベースは読み取り専用で開くので、TableSkim がデータベースを変更することはありません。SQL でクエリすることはできます（[SQL の実行](sql.md) を参照）。

![DuckDB データベース：テーブルごとのシートと SQL の結果シート](../images/gui-sql-result.png)

## ASCII 以外の文字を含む名前

日本語などを含むファイル名、シート名、セルの内容は、どのプラットフォームでも扱えます。
