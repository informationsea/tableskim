# キーボードショートカット

[← 目次](README.md)

Web アプリのキーは [Web アプリの使い方](web.md#キーボードショートカット) にあります。

## GUI

macOS では `Ctrl` の代わりに `Cmd` を使います。

| ショートカット  | 動作                                     |
| --------------- | ---------------------------------------- |
| `Ctrl+O`        | ファイルを開く                           |
| `Ctrl+W`        | ウィンドウを閉じる                       |
| `Ctrl+Q`        | 終了                                     |
| `Ctrl+Shift+M`  | 編集モードのオン / オフ                  |
| `Ctrl+S`        | 保存（編集モード）                       |
| `Ctrl+Shift+S`  | 別名で保存（編集モード）                 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 元に戻す / やり直し（編集モード） |
| `Ctrl+V`        | タブ区切りテキストを貼り付け（編集モード） |
| `F2`、`Enter`、文字入力 | 現在のセルを編集（編集モード）   |
| `Delete`、`Backspace` | 選択したセルを空にする（編集モード） |
| `Ctrl+Shift+E`  | 表示をエクスポート                       |
| `Ctrl+C`        | 選択範囲をタブ区切りテキストでコピー     |
| `Ctrl+F`        | 検索（Search ペイン）                    |
| `Ctrl+G`        | 行・セル・列へ移動                       |
| `Ctrl+Shift+F`  | Filter ペイン                            |
| `Ctrl+Shift+I`  | 列の統計                                 |
| `Ctrl+Shift+H`  | ヒストグラム                             |
| `Ctrl+Shift+P`  | 散布図                                   |
| `Ctrl+Shift+G`  | 集計（Group By）                         |
| `Ctrl+Shift+T`  | ファイルの末尾への追従のオン / オフ      |
| `Ctrl+E`        | SQL を実行                               |
| `F1`            | ユーザーマニュアル                       |
| 矢印キー、`Page Up` / `Page Down`、`Home` / `End` | 現在のセルを移動 |
| `Shift`+クリック | 選択範囲を広げる                        |
| ダブルクリック  | セルの値全体を Content ペインに表示（編集モードでは編集） |
| 右クリック      | セル・行・列のメニュー                   |

SQL ウィンドウ内：

| ショートカット         | 動作                                    |
| ---------------------- | --------------------------------------- |
| `Ctrl+Enter`           | 実行                                    |
| `Ctrl+Up` / `Ctrl+Down`| 履歴の前 / 次の SQL                     |
| `Tab`                  | テーブル名・列名・キーワードを補完      |

## ターミナル UI

ターミナル UI で `?` か `F1` を押すと、この一覧を表示します。

### 移動と選択

| キー                                 | 動作                                           |
| ------------------------------------ | ---------------------------------------------- |
| 矢印キー、`h` `j` `k` `l`            | カーソルを移動                                 |
| `Shift`+矢印キー                     | 選択範囲を広げる                               |
| `v`                                  | カーソル移動による選択を開始 / 終了            |
| `Ctrl+A`                             | すべて選択                                     |
| `Esc`                                | 選択を解除                                     |
| `PgUp` / `PgDn`、`Ctrl+B` / `Ctrl+F` | 1 ページ移動                                   |
| `g` / `G`、`Ctrl+Up` / `Ctrl+Down`   | 先頭行 / 最終行                                |
| `Home` / `End`、`0` / `$`            | 先頭列 / 最終列                                |
| `Ctrl+G`                             | 行（`120`）、セル（`B12`、`R12C2`）、列（列名または列記号）へ移動 |
| `Tab` / `Shift+Tab`、`]` / `[`       | 次 / 前のシート                                |

### 表示

| キー                 | 動作                                                          |
| -------------------- | ------------------------------------------------------------- |
| `Enter`、ダブルクリック | セルの値全体をサイドバーに表示（編集モードでは編集）       |
| `S`                  | カーソルのある列の統計をサイドバーに表示（もう一度：セル表示） |
| `B`                  | カーソルのある列のヒストグラム（`Enter`：棒で絞り込み、`Esc`：戻る） |
| `M`                  | 選択した 2 列、なければカーソル付近の数値か日付の列の二次元密度分布（`Enter`：マスで絞り込み、`Esc`：戻る） |
| `A`                  | 集計（Group By）：列の値ごとに行を数えて要約し、シートに表示 |
| `%`                  | 列（または選択した列）の表示形式：桁区切り、小数点以下の桁数、日付の形式 |
| `s`                  | サイドバーを表示 / 非表示                                     |
| `<` / `>`            | 列の幅を狭める / 広げる                                       |
| `x` / `X`            | 列（または選択した列）を隠す / すべての列を表示               |
| `\|`                  | カーソルのある列までを固定（もう一度：解除）                 |

### 並べ替え・フィルタ・検索

| キー       | 動作                                              |
| ---------- | ------------------------------------------------- |
| `o`        | 列で並べ替え：昇順、降順、なし                    |
| `f`        | フィルタを編集（列ごとの条件）                    |
| `=` / `!`  | フィルタ：セルの値と等しい / 等しくない           |
| `F`        | フィルタを解除                                    |
| `/`        | シートを検索（空文字列：検索を解除）              |
| `Ctrl+R`   | `/` プロンプト内：正規表現検索の切り替え          |
| `n` / `N`  | 次 / 前の一致箇所                                 |

### データとファイル

| キー       | 動作                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| `y`、`c`   | 選択範囲をコピー（タブ区切り、OSC 52 経由）                                 |
| `:`        | SQL を実行（DuckDB / SQLite / Parquet / JSON）。`Up` / `Down`：履歴、`Tab`：補完 |
| `w`        | シートを表示どおりに CSV / TSV / Excel / Parquet へエクスポート             |
| `P` / `D`  | Parquet / DuckDB に変換して同じ場所に保存し、開く（`Esc`：中止）            |
| `H`        | 先頭行：見出しの判定と、その逆（列名 / データ）を切り替える（CSV / TSV / Excel） |
| `#`        | `##` で始まる行を読み飛ばす（VCF では既定でオン）                           |
| `E`        | 次の文字コード：UTF-8、UTF-16LE、UTF-16BE、Shift_JIS（CP932）               |
| `r`        | 再読み込み（ファイルを読み直す）                                            |
| `R`        | Auto Revert のオン / オフ                                                   |
| `T`        | ファイルの末尾への追従（`tail -f`）のオン / オフ                            |
| `e`        | ファイルをファイルブラウザーで表示                                          |
| `?`、`F1`  | ヘルプ                                                                      |
| `q`、`Ctrl+C` | 終了（保存していない変更があれば確認。もう一度 `Ctrl+C` で保存せずに終了） |

### 編集

| キー                   | 動作                                                           |
| ---------------------- | -------------------------------------------------------------- |
| `I`                    | 編集モードのオン / オフ（CSV / TSV / Excel）                   |
| `Enter`、`i`、`F2`     | セルを編集（編集モード）                                       |
| `Enter` / `Tab` / `Esc` | 編集中：確定して下へ / 確定して右へ / 取り消し                 |
| `Delete`、`Backspace`  | 選択したセルを空にする（編集モード）                           |
| 貼り付け               | タブ区切りテキストを選択したセルに貼り付け（編集モード）       |
| `u` / `Ctrl+R`         | 元に戻す / やり直し（編集モード）                              |
| `Ctrl+S`               | 保存（編集モード）                                             |

### フィルタダイアログ

| キー       | 動作                                              |
| ---------- | ------------------------------------------------- |
| `↑` / `↓`  | 行を移動                                          |
| `Tab`      | 次の項目：列、演算子、値                          |
| `←` / `→`  | 列・演算子・All / Any を変更                      |
| `Ctrl+N`   | 条件を追加                                        |
| `Ctrl+D`   | 条件を削除                                        |
| `Ctrl+U`   | 値を消去                                          |
| `Enter`    | 適用                                              |
| `Esc`      | 取り消し                                          |

### ヒストグラム

| キー                 | 動作                                      |
| -------------------- | ----------------------------------------- |
| `↑` / `↓`、`k` / `j` | 棒を選ぶ                                  |
| `←` / `→`、`h` / `l` | 前 / 次の列                               |
| `Enter`              | シートを選んだ棒の行に絞り込む            |
| `F`                  | フィルタを解除                            |
| `Esc`、`B`、`q`      | シートに戻る                              |

### 二次元密度分布

| キー                 | 動作                                      |
| -------------------- | ----------------------------------------- |
| 矢印、`h j k l`      | マスを選ぶ                                |
| `x` / `X`            | X の列を次 / 前の列にする                 |
| `y` / `Y`            | Y の列を次 / 前の列にする                 |
| `t`                  | X と Y を入れ替える                       |
| `L`                  | 色の目盛りを対数 / 線形に切り替える       |
| `Enter`              | シートを選んだマスの行に絞り込む          |
| `F`                  | フィルタを解除                            |
| `b`                  | X がテキスト：箱ひげ図 / 密度分布         |
| `Esc`、`M`、`q`      | シートに戻る                              |

### Group By ダイアログ

| キー                 | 動作                                      |
| -------------------- | ----------------------------------------- |
| `↑` / `↓`、`k` / `j` | 行を移動                                  |
| `g`、`Space`         | その列でのグループ化のオン / オフ         |
| `a`                  | その列の要約のオン / オフ                 |
| `←` / `→`、`Space`   | 最後の行：関数を選ぶ、オン / オフ         |
| `Enter`              | 集計                                      |
| `Esc`                | 取り消し                                  |

### Format ダイアログ

| キー                 | 動作                                      |
| -------------------- | ----------------------------------------- |
| `↑` / `↓`            | 行を移動                                  |
| `←` / `→`、`Space`   | 設定を変える                              |
| `Delete`             | 表示形式を元に戻す                        |
| `Enter`              | 適用                                      |
| `Esc`                | 取り消し                                  |
