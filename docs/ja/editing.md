# セルの編集

[← 目次](README.md)

TableSkim はファイルを閲覧用に開きます。**編集モード**に入らない限り、どんな操作をしてもファイルは変わりません。編集モードでは、セルの値を変更してファイルを保存できます。

| 形式                                                   | 編集 |
| ------------------------------------------------------ | ---- |
| CSV、TSV、VCF などのテキストファイル（圧縮ファイルを含む） | 可   |
| Excel（`.xlsx`、`.xlsm`）                              | 可   |
| Parquet、JSON、DuckDB、SQLite、SQL の結果              | 不可 |

変更できるのはセルの値だけです。行や列の追加・削除はできません。

## 編集モード

- GUI：**Edit → Edit Mode**（`Ctrl+Shift+M`）。ウィンドウのタイトルに `[Editing]` と表示します。
- ターミナル UI：`I`。ステータスバーに `EDIT` と表示します。

編集モードはファイルのすべてのシートに共通です。保存や再読み込みの後も続き、別のファイルを開くと解除されます。保存していない変更があるときに編集モードを抜けようとすると、先に保存するかどうかを尋ねます。

## セルを変更する

GUI では次のとおりです。

- `F2`、`Enter`、ダブルクリックで現在のセルを編集します。文字を入力すると、セルの値を入力した文字で置き換えます。
- セルの編集中は、`Enter` で確定して下へ、`Tab` で確定して右へ移動します（`Shift` を押すと上 / 左）。`Esc` で取り消します。`Alt+Enter` でセル内に改行を入れます。ほかの場所をクリックしても確定します。
- `Delete` か `Backspace` で選択したセルを空にします。
- **Edit → Paste**（`Ctrl+V`）で、TableSkim や表計算ソフトからコピーしたセルなどのタブ区切りテキストを、選択したセルから貼り付けます。値が 1 つだけなら、選択範囲全体をその値にします。
- **Edit → Undo**（`Ctrl+Z`）と **Edit → Redo**（`Ctrl+Shift+Z`）。

固定した列のセルは、小さなダイアログで編集します。

ターミナル UI では次のとおりです。

- `Enter`、`i`、`F2`、ダブルクリックで、カーソルのセルをステータス行で編集します。`Enter` で確定して下へ、`Tab` で確定して右へ移動し、`Esc` で取り消します。`Ctrl+U` で入力を消去します。
- `Delete` か `Backspace` で選択したセルを空にします。
- ターミナルに貼り付けると、タブ区切りテキストを選択したセルに貼り付けます。
- `u` で元に戻し、`Ctrl+R` でやり直します。

編集モードの外では、これらのキーは通常どおりに働きます（たとえば `Enter` はセルをサイドバーに表示します）。

編集したセルは保存するまで緑色で表示します。保存していない変更がある間は、タイトル（GUI）やステータスバー（ターミナル UI）の先頭に `*` を付けます。元に戻す・やり直すはシートごとに働きます。

### 入力した値の扱い

- **テキストファイル**：すべてのセルが文字列です。入力したとおりに保存します。
- **Excel**：入力した文字列がセルの型として読めれば、型を保ちます。数値のセル（と空のセル）は数値、日付・日時のセルは `2024-03-15` や `2024-03-15 09:30` のような ISO 形式の日付、真偽値のセルは `TRUE` / `FALSE` を受け付けます。それ以外は文字列になり、文字列のセルは文字列のままです（`007` の先頭の 0 も残ります）。空にするとセルを消去します。

次のセルは編集できません。Excel の数式・エラー値・文字列として表示している時刻（`hh:mm:ss`、`[h]:mm:ss`）、結合セルに隠れたセル（左上のセルを除く）、ヘッダ行、まだ読み込んでいない行です。

### 並べ替えとフィルタ

編集した行はその場に残ります。表計算ソフトと同じく、並べ替えとフィルタは変更したときにだけ適用し直します。検索・列の統計・ヒストグラムは新しい値でやり直します。

## 保存

- GUI：**File → Save**（`Ctrl+S`）。**File → Save As...**（`Ctrl+Shift+S`）では同じ形式でコピーを保存し、それを開きます。
- ターミナル UI：`Ctrl+S`。

保存しても、変更していない部分はそのまま残ります。

- **テキストファイル**：編集した行だけを書き直します。ほかの行はバイト単位でそのままです。引用符、改行（LF / CRLF）、`##` で始まる行、文字コード（UTF-8、UTF-16、Shift_JIS）、BOM、圧縮（gzip、bgzip、bzip2、xz、zstd）を保ちます。編集した行は同じ区切り文字で、必要なところだけ引用符で囲んで書きます。文字コードにない文字（Shift_JIS のファイルの絵文字など）があると、メッセージを表示して保存を中止します。
- **Excel**：編集したセルだけが変わります。ほかのシート、書式、数式、結合セルは残ります。数式は Excel で開いたときに計算し直されます。

新しいファイルを元のファイルの隣に書き、書き終えてから元のファイルと置き換えます。保存に失敗しても元のファイルは変わりません。ファイルのアクセス権は保ち、シンボリックリンクも同じファイルを指したままです。保存後はファイルを開き直します（位置・並べ替え・フィルタは保ちます）。元に戻す履歴は新しく始まります。

TableSkim で開いた後にほかのプログラムがファイルを変更していた場合は、保存に失敗します。Save As を使うか、ファイルを再読み込みしてください（変更は失われます）。

bgzip のファイルは bgzip のブロックで書き直しますが、そのファイル用に作った索引（`.tbi`、`.csi`）とは合わなくなるので、作り直してください。

## 保存していない変更

保存していない変更が失われる前に確認します。ウィンドウを閉じるとき、終了するとき、ファイルを再読み込み（Revert）するとき、ファイルを読み直すことになるヘッダ・`##`・文字コードの設定を変えるときです。

- GUI：**Save**（保存）、**Don't Save**（保存しない）、**Cancel**（取り消し）。
- ターミナル UI：`y` で保存、`n` で破棄、`Esc` で取り消し。もう一度 `Ctrl+C` を押すと保存せずに終了します。

保存していない変更がある間は、Auto Revert はファイルを読み直しません。その間にファイルが変更されると、タイトルやステータスバーに `(changed on disk)` と表示します。

**Export View** は保存していない変更を含めてシートを書き出します。**Convert to Parquet / DuckDB** はファイルを読むので、最後に保存した内容を変換します。[エクスポートと変換](exporting.md) を参照してください。
