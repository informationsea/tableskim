# TableSkim ユーザーマニュアル

TableSkim は、表形式のファイルを軽快に閲覧するためのビューアです。大きな
CSV ファイル、Excel ブック、Parquet や JSON ファイル、DuckDB / SQLite
データベースを開くと、すぐにスクロールを始められます。行はバックグラウンドで読み込まれるので、読み込み中も操作が止まりません。

TableSkim は 1 つのプログラムに 2 つの画面を備えています。

- デスクトップ向けの **グラフィカルインターフェース（GUI）**
- SSH 接続先などのターミナルで使う **ターミナルインターフェース（TUI）**

どちらでも同じ機能が使えます。並べ替え、フィルタ、検索、列の統計、ヒストグラム、散布図、集計（Group By）、SQL、列の非表示と固定、数値と日付の表示形式、伸びていくファイルへの追従（`tail -f`）、エクスポート、そして編集モードでの CSV / TSV・Excel ファイルのセルの編集です。

同じコアを Web ブラウザで動かす **Web アプリ** もあります。インストールは不要で、開いたファイルはアップロードされません。編集とファイルへの追従を除いて、上の機能が使えます（[Web アプリの使い方](web.md) を参照）。

![TableSkim のウィンドウ](../images/gui-main-window.png)

画面のメニュー名や表示は英語です。このマニュアルでは、メニュー項目などは画面の表記どおり英語で示します。
