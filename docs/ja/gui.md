## ウィンドウの構成

![メインウィンドウ](../images/gui-main-window.png)

- **メニューバー**：File、Edit、View、Window、Help。macOS ではシステムのメニューバーに表示されます。
- **列見出し**：列名、並べ替えボタン（右端の小さな矢印）、その列にフィルタが掛かっているときはフィルタの印。左端の小さな印は列が何を含んでいそうかを表します：`#` は数値、`@` は日付、`?` は真偽値（[列の型と表示形式](#列の型と表示形式) を参照）。
- **行番号**：現在の表示（並べ替え・フィルタ適用後）での行の位置。
- 下部の **シートタブ**：シートごとに 1 つ。フィルタが掛かったシートは名前の後ろに `(filtered)` と表示されます。
- 右側の **サイドバー**（最初は非表示）：Content、Search、Filter、
  Statistics の各ペイン。

ファイルはそれぞれ別のウィンドウで開きます。**Window** メニューに開いているウィンドウが一覧表示され、切り替えられます。

## ファイルを開く

- **File → Open...**（`Ctrl+O`）、または空のウィンドウの **Open...** ボタン。ファイルダイアログでは対応形式すべてを選べます。
- **File → Open Recent**：最近開いた 10 個のファイルを新しい順に表示します（すべてのウィンドウで共通）。**Clear Recent Files** で一覧を空にします。開けなくなったファイルは一覧から外れます。
- コマンドラインで指定する：`tableskim a.csv b.xlsx`
- macOS：アプリケーションのアイコンにファイルをドロップするか、Finder の「このアプリケーションで開く」を使う。

すでにファイルを表示しているウィンドウから開いたファイルは、新しいウィンドウで開きます。**File → Close**（`Ctrl+W`）でウィンドウを閉じ、
**File → Quit**（`Ctrl+Q`）で TableSkim を終了します。

行はバックグラウンドで読み込みます。表はすぐに表示され、まだ読み込んでいないセルは読み込まれ次第埋まっていきます。その間もウィンドウは操作できます。

## 移動と選択

- マウスホイールやスクロールバーでスクロールするか、矢印キー、
  `Page Up` / `Page Down`、`Home` / `End` で現在のセルを移動します。
- セルをクリックして選択し、ドラッグか `Shift`+クリックで範囲を選択します。
- 行番号をクリックすると行全体を、列名をクリックすると列全体を選択します。
- 列見出しの境界をドラッグすると列の幅を変えられます。

## コピー

**Edit → Copy**（`Ctrl+C`）で、選択したセルをタブ区切りテキスト（TSV）としてコピーします。表計算ソフトにそのまま貼り付けられます。非表示の列は含まれません。セル内のタブと改行は空白に置き換え、二重引用符で始まるセルは貼り付けたときに元の値に戻るよう引用符で囲みます。選択範囲にまだ読み込まれていない行があると、その行は飛ばし、何行コピーしたかをメッセージで知らせます。

## 指定した位置へ移動

**Edit → Go To...**（`Ctrl+G`）で次の場所へ移動できます。

- 行番号：`120` など
- セル：`B12` または `R12C2`
- 列：列記号（`AB`）または列名（`Salary`）。列名はまず完全一致で、次に大文字・小文字を区別せずに探し、列記号より優先されます。

![Go To ダイアログ](../images/gui-goto.png)

## サイドバー

**View → Show sidebar** でサイドバーを表示・非表示にします。検索、フィルタ、列の統計を使ったときにも自動的に表示されます。左端をドラッグすると幅を広げられます。

**Content** ペインには、選択中のセルの値全体をペインの幅で折り返して表示します。長い文字列を読むのに便利です。セルをダブルクリックすると開きます。

![Content ペイン](../images/gui-content-pane.png)

## 並べ替え

列見出し右端の **並べ替えボタン**（小さな矢印）をクリックすると、その列で並べ替えます。1 回目で昇順、2 回目で降順、3 回目でファイルの順序に戻ります。見出しの矢印が現在の向きを示します。ある列で並べ替えると、それまでの並べ替えは解除されます。

![Age 列で降順に並べ替えたところ](../images/gui-sorted.png)

列見出しを右クリックすると列メニューが開きます。**Sort Ascending**（昇順）、
**Sort Descending**（降順）、**No Sort**（並べ替えなし）のほか、フィルタ、統計、ヒストグラム、列の非表示と固定の項目があります。

![列見出しのメニュー](../images/gui-header-menu.png)

値の比較方法（数値、日付、文字列、空のセル）は
[並べ替え・フィルタ・検索・統計](filtering.md) で説明しています。

## フィルタ

### クイックフィルタ

セルを右クリックして **Filter: = "値"** を選ぶと、その列が同じ値の行だけを表示します。**Filter: ≠ "値"** を選ぶと、その値の行を除きます。クイックフィルタは、現在のフィルタに条件として追加されます。

![クイックフィルタのあるセルメニュー](../images/gui-cell-menu.png)

### Filter ペイン

**Edit → Filter...**（`Ctrl+Shift+F`）、または列メニュー・セルメニューの
**Filter by This Column...** で Filter ペインを開きます。

![2 つの条件を設定した Filter ペイン](../images/gui-filter-pane.png)

- **Match: All / Any**：すべての条件に一致する行（AND）か、いずれかの条件に一致する行（OR）を表示します。
- 各条件は **列**、**演算子**、**値** からなります。**×** ボタンで条件を削除します。
- **+ Add condition** で条件を追加します。
- **Apply**（または値の欄で `Enter`）でフィルタを適用します。その下の行に「4 rows of 54」のように結果が表示されます。
- **Clear** ですべての条件を削除します。

![フィルタの演算子](../images/gui-filter-ops.png)

演算子は `contains`（含む）、`not contains`（含まない）、`=`、`≠`、`<`、
`≤`、`>`、`≥`、`is empty`（空）、`is not empty`（空でない）、`matches`、
`not matches`（正規表現）、`is a number`（数値）、`is a date`（日付）です。比較はセルの型に従います。数値は数値として、日付は日付として比較し、`= 2024-01-31` はその日のどの時刻にも一致します。詳しくは [並べ替え・フィルタ・検索・統計](filtering.md) を参照してください。

**Edit → Clear Filter**、または列メニュー・セルメニューの **Clear Filter**
でフィルタを解除します。

## 検索

**Edit → Find...**（`Ctrl+F`）で Search ペインを開きます。文字列を入力して
`Enter` を押すか **Search** をクリックします。

![「watanabe」を検索したところ](../images/gui-search-pane.png)

- 一致したセルは表の中で強調表示され、一覧にすべての一致箇所の行・列・値が表示されます。一覧の項目をクリックするとその位置へ移動します。
- 大文字・小文字を区別せず、セル内のどこにあっても一致します。
- **Regex** にチェックを入れると、正規表現（RE2 構文）で検索します。
- 検索はバックグラウンドで実行され、進み具合と一致数が状態欄に表示されます。

## 列の統計

**Edit → Column Statistics**（`Ctrl+Shift+I`）、または列メニュー・セルメニューの **Column Statistics** で、現在の列の Statistics ペインを開きます。上部の一覧から別の列を選べます。

![Salary 列の統計](../images/gui-stats-pane.png)

- 概要には **行数**（Rows）、**空のセル数**（Empty）、**異なる値の数**
  （Distinct）、数値の列では **数値の数**（Numbers）、**最小**（Min）、
  **最大**（Max）、**合計**（Sum）、**平均**（Mean）、**標準偏差**（Std dev）を表示します。
- その下の表には、**最頻値**（Most frequent）を件数と割合とともに一覧します。
- 統計は現在の表示の行が対象なので、フィルタに追従します。
- 値を **ダブルクリック** すると、その値でフィルタします。**右クリック**
  すると **Filter: =**、**Filter: ≠**、**Copy Value** が選べます。
- 概要と一覧の境界をドラッグすると大きさを変えられます。
- **Cancel** で、大きなファイルで時間のかかる計算を中止します。

## ヒストグラム

どのグラフを使い、どう読むかは、[グラフと集計](charts.md) で例とともに説明しています。

**Edit → Histogram...**（`Ctrl+Shift+H`）、または列メニュー・セルメニューの
**Histogram** で、現在の列のヒストグラムを別ウィンドウで開きます。上部の
**Column** 一覧から別の列を選べます。その横には「53 numbers in 30 bins,
1 empty」（53 個の数値を 30 区間に集計、空 1 件）のように集計内容が表示されます。

![Salary 列のヒストグラム](../images/gui-histogram.png)

- **数値** は、50000 や 0.2 のような切りのよい幅の約 30 区間（ビン）に集計します。整数の列で値の範囲が 30 程度以内（年齢 20〜45 など）のときは、値ごとに 1 本の棒になります。
- **日付・日時** は、列の範囲に応じて日・週・月・年などの単位の区間に集計します。
- **その他の列**（文字列）は、代わりに最頻値を横棒で表示します。
- **棒にマウスを重ねる** と、グラフの下に `[600000, 650000): 4 (7.5%)` のように範囲と件数が表示されます。範囲は下限を含み上限を含みません（`[` と
  `)`）。ただし数値の最後の棒は両端を含みます（`[1450000, 1500000]`）。
- **棒をダブルクリック** すると、シートをその棒に含まれる行に絞り込みます。ヒストグラムは残った行で計算し直されるので、段階的に絞り込んでいけます。
  **Edit → Clear Filter** ですべての行に戻ります。

![日付の列のヒストグラム（2 年ごとの区間）](../images/gui-histogram-dates.png)

ヒストグラムは常にシートの現在の表示に追従します。Filter ペインなどでフィルタを変えると計算し直され、概要に「(filtered rows)」と表示されます。下の図は
1994〜1995 年の棒をダブルクリックしたところです。シートにはその 6 行だけが表示され、ヒストグラムはそれを月ごとの区間で表示しています。

![棒をダブルクリックした後：絞り込まれたシートとそのヒストグラム](../images/gui-histogram-filtered.png)

文字列の列では 1 本の棒が 1 つの値に対応し、ダブルクリックするとその値で絞り込みます。

![文字列の列の最頻値](../images/gui-histogram-text.png)

区間の決め方は [並べ替え・フィルタ・検索・統計](filtering.md#ヒストグラム)
で説明しています。

**Save Image...** で、グラフを PNG か SVG ファイルに書き出します（名前の拡張子、またはダイアログで選んだ種類で決まります）。画像はウィンドウに表示されているとおりの大きさのグラフで、軸の下に列名が入ります。

## 散布図と二次元密度分布

**Edit → Scatter Plot...**（`Ctrl+Shift+P`）、または列メニュー・セルメニューの
**Scatter Plot** で、2 つの列の関係を別ウィンドウに描きます。2 列以上を選択しているときは最初の列が X、最後の列が Y になります。そうでなければ、数値か日付を含む列を（現在のセルの周りの行から判断して）選びます。Y は現在の列か、それに最も近いそのような列、X は Y の左で最も近いそのような列（なければ右の列）です。上部の **X** と **Y** で列を、**Show** で表示の種類を選びます。

- **Points**（散布図）は 1 行を 1 つの点として描きます。点が重なるほど濃く見えるので、密集した部分がわかります。大きな表では最大 20 万行を無作為に抽出して描きます（概要にそう表示されます）。抽出結果は毎回同じです。
- **Density**（二次元密度分布）は、描画範囲を約 50 × 50 のマス目に分け、各マスの行数を濃い紫（少ない）から黄色（多い）までの色で表します。右側に色の目盛りがあります。**Log color scale**（既定でオン）にすると、非常に密集したマスの隣でも、行数の少ないマスが見えるようになります。行のないマスは空白です。密度分布は常にすべての行を数えます。

![2 つの数値の列の散布図](../images/gui-scatter.png)

Y は数値か日付である必要があります。X は数値・日付のほか、テキストでもかまいません（下の [X がテキストのとき：箱ひげ図](#x-がテキストのとき箱ひげ図) を参照）。どちらかの値が空、または別の種類の値である行は描かれず、概要に「skipped」として数えられます。

概要の下の行には、`r = 0.0945, R² = 0.0089, y = 2641.23 x + 744351` のように 2 つの列の関係の強さが表示されます。ピアソンの相関係数 *r*（−1〜1）、その 2 乗の *R²*、最小二乗法による回帰直線です。点の抽出ではなく、描いたすべての行から計算します。**Regression line** でその直線をグラフに描きます。日付の列では値がマイクロ秒単位になってしまうため、直線の式は表示しません。

- **点にマウスを合わせる** と、グラフの下にその値と行番号が表示されます。**クリック** すると、シートの現在のセルがその行へ移動します。
- **密度分布のマスにマウスを合わせる** と、`x [-30000, -25000) × y [60, 65): 22 rows (0.2%)` のように範囲と件数が表示されます。**ダブルクリック** すると、シートをそのマスの行に絞り込みます。
- **長方形をドラッグ** すると（どちらの表示でも）、X と Y の値がその中にある行にシートを絞り込みます。

![同じ列の二次元密度分布](../images/gui-density.png)

ヒストグラムと同じく、グラフはシートの現在の表示に追従するので、絞り込んだ後は残った行で描き直されます。**Edit → Clear Filter** ですべての行に戻ります。詳しくは [並べ替え・フィルタ・検索・統計](filtering.md#散布図と二次元密度分布) を参照してください。

### X がテキストのとき：箱ひげ図

X の列がテキスト（都市名や部署名など）のときは、その値がカテゴリになり、カテゴリごとに列を割り当てます。多い順に上位 30 個の値と、残りをまとめた **(other)** です。このとき **Show** は **Box Plot** に切り替わります（Box Plot はこのときだけ選べます）。

![City ごとの Age の箱ひげ図](../images/gui-boxplot.png)

- **箱** はカテゴリの Y の値の第 1 四分位数から第 3 四分位数までで、**中央値** を太線、**平均** を赤い × で示します。**ひげ** は箱から箱の高さの 1.5 倍以内にある最も遠い値まで伸び、それより外の値は小さな丸で描きます。
- **箱を指す** と、カテゴリの行数、最小値、四分位数、最大値、平均、外れ値の数をグラフの下に表示します。**ダブルクリック** すると、シートをそのカテゴリに絞り込みます。
- **Density** では、カテゴリごとの Y のヒストグラムを色付きのマスで並べて表示します。マスをダブルクリックすると、そのカテゴリと範囲に絞り込みます。
- **Points** では、各カテゴリの点をその列の幅に横へ散らして描き、点が重なって隠れないようにします。

カテゴリには相関係数や回帰直線はなく、長方形のドラッグもできません。

### グラフの保存

**Save Image...** で、グラフを表示どおり（グラフの種類、色の目盛り、回帰直線、軸の見出しの列名）に PNG か SVG ファイルに書き出します。種類は名前の拡張子（`.png` か `.svg`）、またはファイルダイアログで選んだ種類で決まります。SVG ファイルでは線や文字がどの大きさでもくっきり表示されます。散布図の点は、SVG の中に画像として入ります。

## 集計（Group By）

例を交えた使い方は [グラフと集計](charts.md#表に集計するgroup-by) も参照してください。

**Edit → Group By...**（`Ctrl+Shift+G`）か、列メニューの **Group By…** で、現在のシートの行をいくつかの列の値ごとに数え、結果を **Group By** という新しいシートに表示します。ピボットテーブルや SQL の `GROUP BY` に当たる機能です。

![Group By ダイアログ](../images/gui-group-by.png)

- **Group by**：これらの列の値がすべて等しい行を 1 つのグループにします。最初は選択中の列（または右クリックした列）にチェックが付いています。1 つも選ばないと全行が 1 グループになり、全体の合計などが得られます。
- **Aggregate**：各グループで要約する列。下でチェックした関数で要約します：**count**（空でない値の数）、**distinct**（異なる値の数）、**sum**、**mean**、**min**、**max**、**std dev**（標本標準偏差）。

結果はグループごとに 1 行で、グループの値の並べ替え順に並びます。列は、グループ化した列、**count**（グループの行数）、そして要約した列と関数ごとの `Salary sum` のような列です。現在の表示の行を対象にするので、フィルタに従います。

![City ごとの行数と Salary の合計・平均](../images/gui-group-by-result.png)

**Group By** シートは、ほかのシートと同じように並べ替え、フィルタ、エクスポート、さらに集計ができます。もう一度集計すると置き換わります。結果はその時点のスナップショットで、元のシートが変わっても更新されませんが、ファイルを再読み込みしても残ります。空のセルはそれだけで 1 つのグループになります。値の比較方法は [並べ替え・フィルタ・検索・統計](filtering.md#集計group-by) を参照してください。

## 列の非表示と固定

### 列を隠す

列見出しを右クリックして **Hide Column** を選びます。複数の列を選択しているときにそのうちの 1 つを右クリックすると、**Hide Columns** で選択した列をまとめて隠せます。**View → Show All Columns**（または列メニューの
**Show All Columns**）で再び表示します。

隠した列は、カーソル移動、コピー、エクスポートでは飛ばされます。並べ替え、フィルタ、統計には引き続き使えます。

### 列を固定する

列見出しを右クリックして **Freeze Columns up to Here** を選ぶと、その列とそれより左の列が、横にスクロールしても動かなくなります。列メニューの
**Unfreeze Columns** か **View → Freeze Columns** で解除します。少なくとも
1 列は固定せずに残す必要があります。

![ID と Name を固定して右にスクロールしたところ（Email 列は非表示）](../images/gui-frozen.png)

## 列の型と表示形式

TableSkim は最初に読んだ 1,000 行から各列が何を含んでいるかを判断し、見出しに印を付けます：数値は `#`、日付・日時は `@`、真偽値（TRUE / FALSE）は `?`。テキストや混在した列には印を付けません。テキストのセルは読み取れる型として数えるので、`42` や `3.5` が並ぶ CSV の列は数値の列です。値の 90% がそろっていれば、紛れ込んだ値（数値の中の `-` など）があっても型は変わりません。

列見出しのメニューの **Format** で、列の値の表示方法を変えられます。サブメニューの 1 行目には「Type: Number (whole numbers)」のように列の型を表示します。

![列の Format メニュー](../images/gui-format-menu.png)

- **Thousands Separator**：`1234567.5` を `1,234,567.5` と表示します。
- **Decimal Places**：**As Stored**（保存されているとおり）か、小数点以下 0〜6 桁に丸めて表示します（`1234.5678` を 2 桁なら `1234.57`）。
- **Date Format**：`2024-01-31`、`2024/01/31`、`01/31/2024`、`31/01/2024`、`2024年1月31日`、`Jan 31, 2024` から選びます。時刻はそのまま表示します。
- **Reset Format**：保存されている値どおりの表示に戻します。

複数の列を選択しているときにそのうちの 1 つを右クリックすると、選択した列すべてに適用します。テキストとして保存された数値や日付も整形します。変わるのは表示だけで、並べ替え、フィルタ、コピー、エクスポートは元の値を使います。表示形式はこのウィンドウのシートごとに保持され、ファイルを再読み込みしても残ります。

DuckDB、SQLite、Parquet、JSON ファイルでは、**Edit → Run SQL...**

SQL ウィンドウには履歴（**History**、`Ctrl+Up` / `Ctrl+Down`）と補完（`Tab`）があります。詳しくは [SQL の実行](sql.md) を参照してください。

## エクスポートと変換

- **File → Export View...**（`Ctrl+Shift+E`）：現在のシートを表示どおり（並べ替え・フィルタ適用後、非表示の列を除く）に CSV、TSV、Excel、Parquet
  で保存します。
- **File → Convert to Parquet / DuckDB...**：テキストファイル（CSV、TSV、
  VCF）を Parquet か DuckDB データベースに変換し、次回から高速に扱えるようにします。

どちらも **Cancel** ボタン付きの進捗ダイアログを表示して実行します。詳しくは
[エクスポートと変換](exporting.md) を参照してください。

## セルの編集

CSV / TSV と Excel ファイルのセルは、編集モードでだけ変更できます。**Edit → Edit Mode**（`Ctrl+Shift+M`）で編集モードを切り替え、編集モード中はタイトルに `[Editing]` と表示します。編集モードでは、`F2`、`Enter`、文字入力、ダブルクリックでセルを編集し、`Delete` で選択したセルを空にします。**Edit → Paste**（`Ctrl+V`）でタブ区切りテキストを貼り付け、**Edit → Undo** / **Redo** で変更を取り消し・やり直し、**File → Save**（`Ctrl+S`）か **File → Save As...**（`Ctrl+Shift+S`）で保存します。編集したセルは保存するまで緑色で表示します。詳しくは [セルの編集](editing.md) を参照してください。

## 変更されたファイルの再読み込み

- **File → Revert**：ファイルをディスクから読み直します。
- **File → Auto Revert**（既定でオン）：ファイルを定期的に（ウィンドウがアクティブなときは 1 秒ごと、それ以外は 5 秒ごと）確認し、変更されていれば読み直します。ほかのプログラムが書き込んでいるファイルを見張るのに便利です。
- **File → Follow End of File**（`Ctrl+Shift+T`）：`tail -f` のように、伸びていくファイルの末尾を表示し続けます。ファイルを 0.5 秒ごとに確認し（Auto Revert のオン・オフにかかわらず）、行が増えるたびに現在のセルを最後の行に移します。圧縮されていない CSV / TSV ファイル（UTF-8 か Shift_JIS）では追記された行だけを読むので、大きなログファイルでも追従できます。書き込み途中の行は、行末まで書かれてから表示します。それ以外のファイルや、追記ではなく書き直されたファイルは読み直します。並べ替えやフィルタを掛けたシートでは、新しい行も並べ替え・絞り込みます。もう一度選ぶと追従をやめます。
- **File → Show File in File Browser**：ファイルのあるフォルダをシステムのファイルマネージャーで開きます。

再読み込みの後、SQL の結果シートは最後のクエリを実行し直して更新されます。保存していない編集があるときは、Revert は破棄してよいか確認し、Auto Revert は読み直しません（その間にファイルが変更されると、タイトルに `(changed on disk)` と表示します）。
